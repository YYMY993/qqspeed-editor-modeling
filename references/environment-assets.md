# 环境成品选件记录

2026-11-24 在 IDC 构建区实际浏览了「环境」五个子类。下列图为原始面板连续滚动截图，相邻列有重叠。悬停黑底浮签有时挡住邻卡名称，应读卡片底部灰条。

| 子类 | 观察到的卡片 | 用途及限制 |
|---|---|---|
| [石头](evidence/environment-1124/石头.jpg) | 岩石1–21 | 岩石17有雪顶和台阶状岩壁，岩石18轮廓较扁，可作低矮雪沿候选。岩石19–21偏暖色，选材时注意色温。 |
| [树木](evidence/environment-1124/树木.jpg) | 树1–15 | 城市阔叶树优先对照树10的浅绿宽冠、树2和树12的分层冠形；树7是白色锥状雪树候选。树3、树14、树15分别有粉、黄、红色冠形。 |
| [花草](evidence/environment-1124/花草.jpg) | 花草1–15 | 花草10呈宽叶丛、花草12呈低矮团状，适合树脚与石缝点缀。 |
| [远景](evidence/environment-1124/远景.jpg) | 远景1–15 | 远景5、13–15有浅蓝或白色山脊轮廓，适合赛道背景候选。卡片不能证明有可滑的实体表面。 |
| [氛围](evidence/environment-1124/氛围.jpg) | 雪花、绿叶、黄叶、飞鸟等特效 | 用于环境动态；没有实测占用、覆盖范围、播放方式。 |

[岩石17场景实拍](evidence/environment-1124/岩石17实拍.png)。以默认大小单次拖入，地图占用 56,835 → 56,860，增量 25。岩石顶面偏平，与雪具小屋相比体量较大。后续双峰岩试摆分别使用岩石17、岩石9，各增 25、20，合计 45。岩石18、树木和远景等表中候选目前只有卡片证据。尺寸、贴地、碰撞与占用分别记录。

造景时按玩家距离与用途先挑主体。需要覆雪岩壁时先看成品是否已带积雪，优先利用现成轮廓、纹理与遮挡；拼第二块前判断其是否真正改善缺口、坡脚或转折。缩放搭接后留意悬空、重复纹理和阴影接缝。车辆可达的坡面与装饰雪沿分别验收，实际滑行或碰撞未测时明确标出。

本地 Aurora3DEditor 配置只提供部分条目和配置权重，与客户端卡片名和覆盖范围存在差异。例如配置仅列少量 Stone/Tree 英文条目，而实际石头面板可见21张卡。不要从编号推导模板ID，不要用配置权重代替地图放置增量。
